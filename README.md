# Application-6
Here is a description on my application 6 Theme Park Ride.
This is a theme park ride that includes 4 buttons. One button to launch the ride, one button to make it go forward, another to make it go reverse, and an emergency stop button for security purposes. This is supposed to be a simulator for Universal which has the buttons as the highest priority to ensure anytime the buttons are pressed they preempt whichever task is being executed.
